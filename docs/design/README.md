# Windows 界面设计

当前采用方案 1「瓷白轻环」：瓷白表面、冷灰背景、蓝色强调、清晰分组。实现保持原生 WinUI 3，不引入 WebView、字体下载或新运行时依赖。深色跟随 Windows；高对比使用系统角色色，运行中切换时刷新共享画刷。

## 界面与交互

- **轮盘**：保留六扇区、中心区、分组外环、搜索和命中几何。纯色底盘替代 Acrylic；选中使用浅蓝背景。100 ms 入场、70 ms 选择反馈，外环同时出现；关闭系统动画时立即更新。窗口预热和重复使用、原地更新画刷保留。
- **设置**：单滚动页，保留唤出轮盘、轮盘外观、停靠栏、文件动作、我的工具、轮盘排布、输出、隐私与离线、语言、启动十个分区及全部配置。640 × 760 DIP 初始尺寸受工作区限制；设置随更改保存，保持原控件自动化标识。
- **停靠栏**：确认拖拽后显示在指针对侧屏幕边缘，不抢焦点。空态、投放边框、文件名与路径分层、全部拖出共用同一视觉。只暂存路径，不移动源文件；空栏在拖拽结束后收起，已有文件则保留。沿用 `edgeDock` 配置键及原有拖拽检测计时器，没有新增常驻轮询。
- **任务与入门**：统一标题层级、12 DIP 卡片圆角、空态和操作间距，保留任务取消、重试、撤销及打开位置行为。
- **托盘**：独立透明蓝色光环与水滴，小尺寸单独绘制。图标只加载一次，优先 `DropHalo.Tray.ico`，失败则读取 EXE 内嵌图标；Explorer 重启后重新注册。

- 圆角：控件 8、卡片 12；轮盘为圆。
- 字体：Windows 原生字体，图标沿用 Segoe Fluent Icons / Segoe MDL2 Assets；无额外图标字体。
- 轮盘背景不透明度仍为 0–100%，仅作用于一层底盘与外环底色；文字、扇区边线、选中区域不淡化。高对比时背景强制不透明，退出高对比后恢复保存的数值。
- 日常热路径不读取图片或建立窗口，不增加持续动画、背景模糊或定时重绘。
- 圆形底盘由 Composition 几何绘制，填充与边线分层以保留独立透明度；入场动画复用，文字未变化时不重复触发布局。启动预热按窗口实际 DPI 走完整唤出路径，并覆盖分组外环尺寸；预热结束不会隐藏等待期间用户新唤出的轮盘。

## 资源与验证

主 Logo、托盘 Logo、PNG 与 ICO 都由 `scripts/gen-icons.py` 生成；不要直接手改产物。母版及预览位于 `exports/`，格式说明见 `src/DropHalo.App/Assets/README.md`。

浅色轮盘的故障检测保留白块告警，并检查中心拖图之外的分布式细节，避免白色设计误报。Core 回归覆盖缩放与噪点；Windows 验收覆盖起拖显示停靠栏、取消、拖入/拖出、设置开关、全配置与托盘资源。

自动显示沿用 `SysDragImage` 信号；没有该信号的拖拽源尚不能保证起拖即显示。真实响应时间、不同 DPI 和运行中主题切换以 Windows 验收记录为准，动画时长不等于实测响应耗时。
